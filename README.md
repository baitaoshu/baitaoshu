# 白桃书

安静地读一本书。中文小说免费在线阅读站。

**站点 → [baitaoshu.com](https://baitaoshu.com)　主页 → [baitaoshu.github.io](https://baitaoshu.github.io)**

---

## 这是什么

一个自建的中文阅读站。793 本在架小说，25 部古典名著的公版全文，打开网页就是正文 —— 没有弹窗、不用装 App、不用登录也能读。

做这个站的原因很简单：中文在线阅读站普遍塞满了插页广告和「下载客户端」的拦截层，而真正值得反复读的古籍，本来就躺在公有领域里，没有任何理由被锁起来。

## 在做什么

| | |
|---|---|
| **精校公版全文** | 二十五部古典名著逐章校对、分回、统一断句，不是随手抓的错字版 |
| **故事地图** | 书里真实可考的地名落到地图上，每个点位标注首次出现的章回与原文摘录，点一下跳到那一回 |
| **浏览器听书** | 系统语音从头念到尾，支持断点续听 |
| **段落点评** | 选中一段即可批注、看他人批注 |
| **全文检索** | 书名、作者、正文一起搜，命中直接落到那一段 |
| **四种界面** | 简体 / 繁體 / 日本語 / English，繁体连书名与正文一并转字形 |

## 技术

Go 后端 + React 阅读器 + MySQL 存章回；封面、静态书页、sitemap 在构建期生成，跑在自己的服务器上。不挂第三方阅读平台，不接广告联盟的插页。
